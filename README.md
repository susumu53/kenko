# 実現健康長寿アプリ (Kenko Longevity App)

> **「健幸五輪モデル」に基づく包括的健康長寿支援Webアプリケーション**
> セルフチェック、PHR記録、科学的健康教育、地域資源・活動マッチングをひとつに統合。

## 🌿 概要

本アプリケーションは、日本老年学的評価研究（JAGES）、東京大学高齢社会総合研究機構（IOG）、厚生労働省「健康日本21（第三次）」などの科学的エビデンスおよび地域実践事例をもとに体系化された**「健幸五輪モデル」**を社会実装するためのWebアプリケーションです。

外部依存ライブラリやフレームワークを使わない純粋な Vanilla Web 技術（HTML5 / CSS3 / JavaScript ES6+）で構築されており、軽量・高速・完全なローカルプライバシー保護（localStorage運用）を実現しています。

## 🎯 主な機能

### 1. 健幸指数セルフチェック（五輪アセスメント）
- **5つの輪・21問の客観的アセスメント**
  - 第1輪：医療・フレイル予防（体重変化、歩行、口腔・オーラルフレイル等）
  - 第2輪：生活習慣・運動（ウォーキング、筋トレ、睡眠休養、野菜摂取・減塩等）
  - 第3輪：社会参加・社会的処方（通いの場、ボランティア、他者との会話、役割等）
  - 第4輪：学び・生きがい（生涯学習、趣味、自然との触れ合い、プラン・デ・ビーダ）
  - 第5輪：環境・デジタル（スマホ活用、住環境、健康モニタリング等）
- **健幸五輪レーダーチャート（HTML5 Canvas）**
- **推定生物学的年齢（体内年齢）**の算出
- **フレイル判定（健常 / プレフレイル / フレイル）**

### 2. PHR（Personal Health Record）ダッシュボード
- 日々の4大指標のワンタップ記録：
  - 🚶 今日の歩数（厚生労働省推奨目標：8,000歩/日）
  - 😴 睡眠時間（適正目標：7時間）
  - 🥗 野菜摂取皿数（健康日本21目標：350g ≒ 5皿）
  - 🤝 社会参加・会話（あり / なし）
- 直近7日間の週間推移グラフ（Canvas製）
- 健康習慣達成バッジシステム

### 3. 学びの道（科学的健康教育・6レッスン）
1. **健康長寿の基礎**：平均寿命と健康寿命の差、延伸のメカニズム
2. **ブルーゾーンの教訓**：Power 9（自然に動く、80%ルール、生きがい、正しい集団等）
3. **ゲロサイエンスと生物学的年齢**：DNAメチル化、エピジェネティック・クロック、生活習慣の可逆性
4. **フレイル予防の三位一体**：栄養（食とお口）× 運動 × 社会参加の好循環
5. **社会的処方の力**：薬ではなく「地域とのつながり」を処方する新潮流
6. **データ駆動型ヘルスケア**：PHRと習慣化のサイエンス
- 各レッスンの確認クイズ＆実践ワークシート機能付き

### 4. つながりマップ & 地域活動ガイド
- **目的別の現実的アクセス先ガイド**：
  - 趣味・文化サークル ➡️ 最寄りの公民館・地区センター（掲示板チラシ）
  - ボランティア・交流サロン ➡️ 市区町村社会福祉協議会（社協）
  - 介護予防体操 ➡️ 役所健康増進課・包括生活支援コーディネーター
- **リアルタイム地域連携・スマートダイレクト検索**：
  - お住まいの都道府県・市区町村名を入力すると、ジモティー（メンバー募集／教室）、Googleマップ（近隣コミセン）、自治体公民館だより、社協への直行リンクを即時自動生成
- **5つの先進事例地域の詳細分析**：
  - 長野県佐久市（住民自治・草の根減塩ぴんころモデル）
  - 愛知県武豊町（JAGES連携・通いの場によるフレイル半減実証）
  - 千葉県市原市（東大連携・電力AI×RIZAPの一気通貫モデル）
  - 長崎県佐世保市（社会的処方・生きがい再生）
  - 広島県神石高原町（過疎地DX・歩数3,800歩増のゲーミフィケーション）

## 🛠 技術スタック

- **フロントエンド**：HTML5, CSS3 (CSSカスタムプロパティ・レスポンシブ Grid/Flexbox), JavaScript (Vanilla ES6+)
- **描画**：Pure HTML5 Canvas (レーダーチャート、週間推移バーチャート)
- **データ管理**：Web Storage API (localStorage)
  - スキーマバージョン管理、JSONエクスポート／インポート機能搭載
- **デザインシステム**：「和のモダニズム」テーマ（常磐緑・藍色・朱色の色彩設計、ダークモード完全対応、48px以上のタッチターゲット確保）

## 🚀 利用方法

### GitHub Pages で利用する場合
リポジトリ公開後、GitHub Pages の URL にアクセスするだけで即座にご利用いただけます。

### ローカル環境で実行する場合
ビルドや `npm install` 等の依存関係は一切ありません。
任意のブラウザで `app/index.html` を直接開くか、ローカルサーバーで実行してください：

```bash
# クローン
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# Python を使った簡易サーバー実行の例
python -m http.server 8000
# http://localhost:8000/ にアクセス
```
