# オンライン受講システム構築 実装計画（note ハイブリッド版）

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** note 有料マガジン + 自作EdTechツール（修了試験・修了証発行）で、個人（法人登録不要）かつ集客力のあるオンライン受講システムを構築する

**Architecture:** note（有料マガジン）でコンテンツ販売・決済・集客を行い、YouTube限定公開で動画配信、Google Formsで修了試験（自動採点）、自作Webアプリ（GitHub Pages）で修了証PDF発行を行うハイブリッド構成。

**Tech Stack:** note（有料マガジン） / YouTube（限定公開） / Google Forms（クイズモード） / Vanilla JS + jsPDF + html2canvas（修了証発行アプリ） / GitHub Pages

**変更経緯:**
- v1: KOMOJU + WordPress → 法人登録が必要で断念
- v2: MOSH → 集客力が弱い（自力集客のみ）
- v3（本版）: note + 自作ツール → 集客力◎（MAU 7,359万）＋差別化（修了証付き講座）＋技術蓄積

## Phase 2: EdTechツール開発

### Task 4: Google Forms で修了試験を作成（3コース分）

**作業場所:** Google Forms
**作業者:** ユーザー（手動）+ Antigravity（問題案作成支援）

**Step 1: 初級修了試験の作成**
- Googleフォームで新規作成
- 「設定」→「テスト」→「テストにする」をON
- 参照資料：健康長寿アドバイザー_初級_台本とスライド設計.md
- 出題数：10〜15問（選択式）
- 合格基準：70%以上（7/10問以上正解）
- 名前・メールアドレスを必須収集
- 自動採点 + 正解解説を設定
- 質問・選択肢のランダム化をON

**Step 2: 中級修了試験の作成**
- 同様の手順で中級用の試験を作成
- 参照資料：健康長寿アドバイザー_中級_台本とスライド設計.md

**Step 3: 上級修了試験の作成**

### Task 5: 修了証発行Webアプリの開発

**作業場所:** ローカル開発環境
**作業者:** Antigravity（コード実装）

**技術構成:**
- HTML5 / CSS3 / Vanilla JavaScript（既存アプリと同じスタック）
- jsPDF（PDF生成ライブラリ、CDN経由）
- html2canvas（HTML→Canvas変換、CDN経由）
- デザイン：既存の「和のモダニズム」テーマを踏襲

**機能:**
1. 受講者名の入力
2. コースレベル（初級/中級/上級）の選択
3. 修了試験合格日の入力
4. 証明番号の自動生成（例：KLA-B-2026-0001）
5. プレビュー表示
6. PDF修了証のダウンロード
7. 検証用QRコード（証明番号から検証ページへのリンク）

**修了証デザイン:**
- A4横向き
- 和風モダンデザイン（常磐緑・藍色ベース）
- 証明番号 + QRコード付き
- 印刷に適した高解像度

**配置:** app/certificate/ ディレクトリに配置し、GitHub Pagesで公開

**完了条件:** ブラウザで修了証を生成・PDF保存できる状態
