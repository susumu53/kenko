# 健康長寿アドバイザー オンライン受講システム — 決済方式の設計

> 更新: 2026-10-02

## 🎯 課題

ターゲット層（シニア・健康意識の高い一般の方）にとって、以下は**ハードルが高い**：
- PayPal（アカウント作成が必要、日本での浸透率低い）
- 銀行振込（口座番号確認・ATM操作が手間）

**求められるもの**：スマホで「ピッ」とできる、日本で馴染みのある決済手段

### ✅ 推奨：アプローチA — Tutor LMS + WooCommerce + KOMOJU

| 項目 | 内容 |

| **利用可能な決済手段** | PayPay, コンビニ決済, クレジットカード, 銀行振込, Paidy(後払い) |

#### なぜ Tutor LMS か（LearnPress との比較）

| 比較項目 | LearnPress 無料版 | Tutor LMS 無料版 |
|---|---|---|
| WooCommerce連携 | ❌ **有料アドオン $49 必要** | ✅ **無料で内蔵** |
| コース・レッスン管理 | ✅ | ✅ |
| クイズ機能 | ✅ | ✅（種類が豊富） |
| 進捗トラッキング | ✅ | ✅ |
| 段階制御 | ❌（有料） | ❌（有料） |
| 修了証 | ❌（有料） | ❌（有料） |

→ **最大の差**：Tutor LMS無料版は**WooCommerce連携が無料**で含まれる。
LearnPressは有料アドオン（$49）が必須。

#### KOMOJU の料金体系

| 項目 | 費用 |
|---|---|
| 初期費用 | **¥0** |
| 月額費用 | **¥0** |
| PayPay手数料 | 約3.5% |
| コンビニ決済手数料 | 約2.75%〜 |
| クレジットカード手数料 | 約3.25% |
| 振込手数料（3万円未満） | ¥220/回 |
| 振込手数料（3万円以上） | ¥410/回 |

例：受講料 ¥5,000 のコースをPayPayで購入 → 手数料 ¥175（3.5%）

#### KOMOJU 導入に必要なもの

- 開業届 or 確定申告書類
- 本人確認書類（運転免許証 or マイナンバーカード）
- 特定商取引法に基づく表記をサイトに掲載
- 審査通過（通常数日〜数週間）

#### 受講者から見た購入フロー

```
コース紹介ページ → 「受講申込」ボタン
  → WooCommerce カート画面
  → 決済方法を選択（PayPay / コンビニ / カード）
  → PayPay選択時：PayPayアプリが起動 → 支払い完了
  → 自動で受講開始 ✅
```

**受講者はPayPayで「ピッ」と払うだけ。アカウント作成の手間なし。**

### アプローチB — LearnPress + Offline Payment（手動PayPay運用）

| 項目 | 内容 |
|---|---|
| **LMS** | LearnPress 無料版 |
| **決済** | Offline Payment（LearnPress内蔵・無料） |
| **運用方法** | 受講者がPayPayで送金 → 管理者が手動で受講承認 |

> [!WARNING]
> **PayPayの重要な規約制限**
> PayPay加盟店のQRコードをWebサイトに掲載することは**規約違反**です。
> オンラインでPayPayを受け付けるには、PayPayオンライン決済APIの正式連携が必須です。

#### 正規の手動運用フロー

```
コース紹介ページ → 「受講申込」ボタン
  → LearnPress Offline Payment 画面
  → 表示：「PayPay ID: ○○○○ に送金してください」
      ※QRコード画像の掲載は不可
  → 受講者がPayPayアプリで手動送金
  → 管理者がPayPay for Business で入金確認
  → 管理者がLearnPress管理画面で注文を「完了」に変更
  → 受講開始 ✅
```

| メリット | デメリット |
|---|---|
| プラグイン費用もKOMOJU審査も不要 | ⚠ PayPay ID送金は個人間取引扱い |
| WooCommerce不要でシンプル | ❌ 管理者の手動承認が毎回必要 |
| 即日で開始可能 | ❌ 入金確認のタイムラグ（受講者を待たせる） |
| | ❌ スケールしない（受講者が増えると破綻） |
| | ⚠ PayPayの事業利用規約グレーゾーン |

## 🏆 推奨：アプローチA（Tutor LMS + WooCommerce + KOMOJU）

### 推奨理由

1. **PayPayが使える** — シニア層に最も馴染みのある決済手段
2. **プラグイン費用ゼロ** — Tutor LMS無料版はWooCommerce連携が無料
3. **完全自動化** — 決済完了 → 即座に受講開始（手動承認不要）
4. **KOMOJU自体も無料** — 初期費用¥0、月額¥0、取引ごとの手数料のみ
5. **複数決済を一括導入** — PayPay、コンビニ、カード、後払いを同時に提供
6. **規約に完全準拠** — PayPayオンライン決済の正規ルート

### 導入に必要な準備

| 準備項目 | 必要なもの |
|---|---|
| KOMOJU審査 | 開業届 + 本人確認書類 + 特商法表記 |
| YouTubeアカウント | 19本の動画アップロード（限定公開） |
| WordPress管理 | Tutor LMS + WooCommerce + KOMOJU Payments インストール |
