# オンライン受講システム構築 実装計画（MOSH版）

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** MOSH プラットフォームを使い、個人（法人登録不要）でオンライン受講システムを構築する

**Architecture:** MOSH（mosh.jp）の「講座」タイプで3コース（初級・中級・上級）を構築。動画は YouTube 限定公開でホスティングし、MOSHの会員サイト機能で購入者限定配信する。決済はMOSH内蔵のStripe連携（カード・銀行振込）を利用。

**Tech Stack:** MOSH (FREEプラン) / YouTube（限定公開）

**変更経緯:** 当初計画の KOMOJU + WordPress（Tutor LMS + WooCommerce）は法人登録（開業届 or 法人格）が審査に必要なため、個人で即開始可能な MOSH に変更。

- FREEプラン（月額¥0）であることを確認

## Phase 2: MOSH でコース作成

### Task 3: 初級コースの作成

**作業場所:** MOSH管理画面

**Step 1: 新規サービスを作成**
- 「サービス」→「新規作成」
- サービスタイプ：**講座**
- サービス名：「健康長寿アドバイザー 初級コース」
- 説明文：初級テキスト（健康長寿アドバイザー（初級）講義テキスト.html）の内容を要約して記載
- 価格を設定（例：¥5,000）
- カバー画像を設定

**Step 2: 会員サイトに5つのレッスンを配置**

| レッスン | タイトル | 内容 |
|---|---|---|
| 1 | 第1回講義 | YouTube動画埋め込み + 講義テキスト要約 |
| 2 | 第2回講義 | YouTube動画埋め込み + 講義テキスト要約 |
| 3 | 第3回講義 | YouTube動画埋め込み + 講義テキスト要約 |
| 4 | 第4回講義 | YouTube動画埋め込み + 講義テキスト要約 |
| 5 | 第5回講義 | YouTube動画埋め込み + 講義テキスト要約 |

- 各レッスンにYouTube限定公開動画のURLを埋め込み
- レッスン説明に講義テキストの該当部分を転記
- 段階的に公開設定（カリキュラム順配信）

**Step 3: コース紹介文の作成**
- 受講対象者
- 学習内容・カリキュラム概要
- 受講後に得られるスキル
- 「初級 → 中級 → 上級の順にご受講ください」の案内

**完了条件:** 初級コースが5レッスン+動画埋め込みで作成され、購入可能な状態

## Phase 3: サイト整備

### Task 6: プロフィール・コース紹介ページの整備

**作業場所:** MOSH管理画面

**Step 1: プロフィールを充実させる**
- プロフィール画像の設定
- 自己紹介文（健康長寿アドバイザーとしての経歴・専門性）
- SNSリンクの設定

**Step 2: 3コースの一覧が分かりやすく表示されることを確認**
- 初級→中級→上級の順に並べる
- 各コースの説明が十分か確認

**Step 3: 特定商取引法に基づく表記の確認**
- MOSHでは販売者情報が自動的に表示される仕組みがあるが、内容の正確性を確認
- 必要に応じて手動で追記：
  - 商品の引渡し時期：決済完了後、即時（オンライン受講開始）
  - 返品・キャンセル：デジタルコンテンツの性質上、受講開始後の返品・返金不可

**完了条件:** プロフィールページが整備され、3コースが一覧表示される
