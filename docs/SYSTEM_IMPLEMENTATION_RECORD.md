## 1. プロジェクト背景と戦略決定の経緯

### 1-1. 決済・配信プラットフォームの変遷
1. **初期案: KOMOJU + WordPress**
   - 断念理由: KOMOJU決済の審査・利用にあたり法人登録が必須要件となっていたため。
2. **比較検討: MOSH vs note**
   - MOSH: オンラインスクール特化型だが、プラットフォーム自体の集客力（SEO・回遊性）が限定的で、SNS等での完全自力集客が前提。
   - **note（採用）:** MAU 7,359万人の巨大メディアプラットフォーム。法人登録不要で即日有料マガジン販売が可能。無料記事による検索流入・ドメインパワーが高く、初期集客に最も有利と判断。
3. **ハイブリッド受講モデルの確定**
   - note（決済・集客・テキスト）＋ YouTube（限定公開による講義動画ホスティング）＋ Google Forms（自動採点クイズモードによる修了試験）＋ 自作Webアプリ（即時PDF修了証発行）を組み合わせることで、**固定費¥0（完全無料）** で本格的なEdTech資格受講システムを実現。

### 1-2. 初級講座の「完全無料開放」戦略の決定（2026-10-03追加）
- **方針転換の目的:**
  1. **認知度・信頼の爆発的獲得:** 超高齢社会において「エビデンスに基づく健康長寿の基礎知識」を無料インフラとして誰でも学べるようにし、note上でのフォロワー数・受講者母数を最大化する。
  2. **差別化されたEdTech体験:** 「無料なのに動画＋教科書レベルの詳細講義テキスト＋修了試験＋正式な公式修了証（PDF・証明番号・QRコード付き）が即時手に入る」という圧倒的価値を提供。
  3. **受講ハードルの撤廃:** 初級受講生が途中で離脱しないよう、従来の「宿題・実践ワーク提出」をすべて排除。
  4. **スムーズなバックエンド展開:** 初級で確固たる自己健康管理を習得した受講生に対し、対人支援や地域リーダーを目指す「中級認定コース（有料）」「上級・認定講師養成コース（有料）」へのステップアップ導線を自然に接続。

## 4. システム連携フロー ＆ 有料コースアクセス制御仕様

### 4-1. 一体化システム連携フロー

```mermaid
sequenceDiagram
    autonumber
    actor 受講生
    participant note as note (無料/有料マガジン)
    participant App as 一体化Webアプリ (GitHub Pages: app/certificate/)
    participant Sheet as 管理者Googleスプレッドシート (GAS)

    受講生->>note: 第5回講義テキスト・限定公開動画を受講完了
    Note-->>受講生: 記事末尾のURLリンクをクリック (?course=beginner または ?course=intermediate&key=xxx)
    受講生->>App: 氏名・メールアドレスを入力（※初級リンクからはコース固定）
    App->>受講生: 15問の選択式試験を出題（進捗バー表示）
    受講生->>App: 回答送信・即時自動採点
    alt 70%以上合格
        App-->>受講生: 合格祝賀画面＋全問の詳細解説を表示
        受講生->>App: 「公式修了証（PDF）を発行」をクリック
        App->>Sheet: 氏名・メアド・コース・得点・証明番号を自動記録（Webhook）
        App-->>受講生: 証明番号・QRコード入り公式PDF修了証を即時ダウンロード！
        App->>note: 完了画面から次のコース（中級/上級）へステップアップ案内
    else 不合格
        App-->>受講生: 不合格画面＋解説確認 ➔ 「もう一度挑戦する」で即時再受験
    end
```

### 4-2. コース別アクセス制御（不正受験防止システム）

初級受講生が未購入の中級・上級試験を勝手に受験できないよう、**2重のアクセス制御ロジック**を実装：

1. **初級リンクのコース固定（URLパラメータロック）:**
   初級note記事末尾のリンク（`.../app/certificate/?course=beginner`）から開いた場合、コース選択プルダウンが「初級コース」に自動固定（ロック）され、中級・上級への勝手な切り替えを抑止します。
2. **有料受講生限定「受講認証キー（パスコード）」の要求:**
   直接アクセス等で「中級」または「上級」を選択した場合、入力フォームに **「🔒 受講認証キー（有料マガジン最終回に記載）」** の入力欄が出現します。
   - **初級:** パスコード不要（誰でも完全無料で受験可能）
   - **中級:** 認証キー `KLA-MID-2026`（※note中級有料マガジンの最終回記事に記載）
   - **上級:** 認証キー `KLA-ADV-2026`（※note上級有料マガジンの最終回記事に記載）
   - ※認証キーが一致しない限り、試験を開始することはできません。
   - ※有料note記事内のリンクに `?course=intermediate&key=KLA-MID-2026` を設定しておけば、購入者はキー入力の手間なくスムーズに受験可能です。
   - ※キーは [`app/certificate/certificate.js`](file:///c:/Users/user/Desktop/desktop/kenko/app/certificate/certificate.js) の `COURSE_PASSCODES` で自由に変更できます。
