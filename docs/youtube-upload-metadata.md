# YouTube 講義動画アップロード用 メタデータ完全台帳

> **対象チャンネル:** [YouTube Studio](https://studio.youtube.com/channel/UCtgqiWVNp_Rr_n3MHIrmkfg)
> **連携先 note:** [note 公式ページ](https://note.com/hero_as_a_hobbty)
> **公開設定:** **すべて「限定公開」**（※「公開」や「非公開」にしないこと）
>
> **使い方:**
> 1. [YouTube Studio](https://studio.youtube.com/channel/UCtgqiWVNp_Rr_n3MHIrmkfg) 右上の「作成」→「動画をアップロード」を開きます。
> 2. 下記のファイル名に合致する動画ファイルをドラッグ＆ドロップします。
> 3. 「タイトル」「説明（概要欄）」「タグ」をそのままコピー＆ペーストしてください。
> 4. 「公開設定」画面で **「限定公開」** を選択して保存します。
> 5. 保存後に発行される **動画URL（共有リンク）をコピー** して、該当するnote記事の有料エリアに貼り付けます。
